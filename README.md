# 🪟 Modal Popup UI

Uma interface moderna de modal popup desenvolvida com foco em interação do usuário e confirmação de ações importantes, utilizando um design elegante e minimalista para melhorar a experiência visual em aplicações web.

---

## 📸 Preview do Projeto

Interface contendo:

- Botão interativo de abertura
- Modal de confirmação moderno
- Fundo com efeito de destaque
- Ícone de alerta estilizado
- Botões de confirmação e cancelamento
- Layout centralizado e responsivo

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Interface clean e moderna
- Efeito de popup centralizado
- Botões com cores destacadas
- Bordas arredondadas suaves
- Layout minimalista
- Animação suave de exibição
- Overlay escurecido no fundo
- Design responsivo

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de componentes interativos utilizando JavaScript, explorando conceitos de manipulação do DOM, efeitos visuais e experiência do usuário.

---

## 📚 Funcionalidades

- Abertura do modal ao clicar no botão
- Confirmação de ações importantes
- Fechamento do popup ao cancelar
- Interface adaptável para diferentes dispositivos
- Estrutura reutilizável para projetos web
